# Задание для ChatGPT: иллюстрации к 501 термину справочника

Это общее задание. Отправьте его в чат один раз в начале каждого потока, затем по одному пункту из пакетов `batches/thread-N-batch-MM.md`. Пакеты уже разложены на 4 потока; в каждом пункте указаны имя файла, термин и индивидуальный промпт.

## Что нужно

Одна иллюстрация на термин астрономического справочника портала «Параллакс». Картинка должна объяснять именно свой термин так, чтобы школьник понял идею без подписи. Подписи и alt-тексты портал хранит отдельно, поэтому **на изображении не должно быть текста, букв, цифр, формул, логотипов и водяных знаков**.

## Единый стиль

- Строгая научно-популярная иллюстрация в духе современного астрономического атласа, без «космических обоев».
- Фон глубокий тёмно-синий `#18233A`, линии и светлые детали `#FBFBF9`.
- Приглушённые акценты: зелёный `#2C7A4B` (зона обитаемости, жизнь), синий `#2A78D6`, оранжевый `#EB6834`, бирюзовый `#1BAF7A`. Цвет звёзд соответствует их температуре: красные карлики — оранжево-красные, Солнце — жёлто-белое, горячие звёзды — бело-голубые.
- Матовая плоская заливка с мягкими градиентами. Без неона, свечения ради эффекта, фиолетовых градиентов и бликов объектива.
- Формат горизонтальный 4:3, не меньше 1024×768.

## Композиция по смыслу

Не рисуйте одну и ту же планету для разных терминов. Выбирайте форму по смыслу:

- **объект** (звезда, галактика, туманность, планета) — «портрет» объекта с правдоподобным видом;
- **процесс** (затмение, прецессия, приливный захват, звёздная эволюция) — последовательность состояний или схема со стрелками;
- **геометрия и измерение** (параллакс, азимут, звёздная величина, красное смещение) — чистая геометрическая схема без подписей;
- **инструмент** (телескоп, спектрограф, интерферометр) — технический разрез или вид устройства;
- **явление на небе** (метеорный поток, полярное сияние, мерцание) — вид глазами наблюдателя с Земли.

## Научная корректность

- Схемы должны быть верными: порядок фаз Луны, положение Солнца, Земли и Луны при затмениях, направление вращения, соотношение размеров, если промпт его требует.
- Если точную схему получить нельзя, рисуйте ясную концептуальную картинку; портал пометит её как «концептуальная иллюстрация».
- Не делайте вид фотографии с телескопа: это рисунок, портал прямо подписывает его как иллюстрацию, созданную нейросетью.
- Не изображайте вымышленных существ, города и «жизнь на экзопланетах».

## Как сдавать результат

Сохраните каждую картинку под именем из пакета, например `43.png`, в папку `services/glossary-rag/data/illustrations/inbox/`. Затем импортируйте их:

```sh
cd services/glossary-rag
python -m scripts.illustrations import --dir data/illustrations/inbox --generator "ChatGPT (аккаунт команды)"
python -m scripts.illustrations verify
```

Импорт проверяет формат, размеры и пропорции, считает SHA-256, кладёт файл в `data/media/illustrations/` и отмечает термин как `generated`. Готовые термины в следующих пакетах не повторяются: пакеты пересобираются командой `python -m scripts.illustrations batches --threads 4`. Перед публикацией редактор просматривает картинки и ставит `review.status = "approved"` в `data/illustrations/manifest.json` либо `status = "rejected"`, чтобы термин вернулся в очередь.
