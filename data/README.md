# Данные справочника

| Путь | Что здесь хранится |
| --- | --- |
| `raw/` | Снимки страниц и ответов Astro4Edu, разложенные по типам. Здесь же исходный SVG карты часовых поясов. |
| `processed/terms/` | Канонические двуязычные записи, по одному JSON на ID термина. Из них сервис строит SQLite и чанки. |
| `raw/reviews/` | Исходный каталог, страницы OAE Reviews, оригинальные PDF и извлечённый текст по страницам с отметками OCR. |
| `processed/articles/` | Статьи проекта, обзорные темы `oae-review-*.json` и постраничные записи PDF `oae-document-*.json`. Источник для SQLite, русских PDF и чанков. |
| `media/original/` | Исходные изображения. Файлы из записей OAE Reviews включены в Git, в том числе общие со словарём. Остальные исходники словаря загружаются отдельно. |
| `media/ru/` | Русские изображения. Журнал надписей, правок и хэшей хранится в `image_edits.json`. |
| `media/ru/review-pdf/` | Готовые русские издания. Пересборка из `processed/articles/` и связанных изображений. |
| `media/localization/` | Словари надписей и локальный OCR-инвентарь `image_ocr.json`. Журнал локализаций находится в `image_edits.json`. |
| `media/illustrations/` | Файлы обложек терминов. |
| `illustrations/manifest.json` | Реестр обложек с путями, атрибуцией и статусами. Сервис читает его при сборке SQLite. |
| `illustrations/selection/` | Ручной отбор и замены по связанным терминам, плюс кэш кандидатов Wikimedia. |
| `illustrations/reports/` | Отчёты импорта и OCR, [просмотр обложек](illustrations/reports/review.html) и таблица покрытия. |
| `eval/assistant/` | Контрольные вопросы, оценка поиска и режимов ответа, результаты эксперимента с размерами чанков. |
| `eval/translation_audit/` | Текущее ревью переводов, журнал исправлений и [отчёт](eval/translation_audit/summary.md). |
| `eval/translation_audit/manual_terms.json` | Ручная сверка отдельных определений с контрольными суммами оригинала и перевода. |
| `eval/review_translation_audit/` | Журналы ручной сверки текстов, ссылок и подписей OAE Reviews (`manual_pages.json`, `manual_media.json`). |
| `eval/review_translation_audit/pdf_source_images.json` | Восстановленные исходные изображения с прозрачностью, номера объектов PDF, контрольные суммы и пути к прежним выгрузкам. |
| `eval/translation_legacy/` | Журналы раннего ревью. Текущий аудит сверяется с ними, чтобы исключить откат прежних исправлений. |
| `index/` | Чанки, индекс FAISS, карта векторов и манифесты. Кэш эмбеддингов хранится здесь локально. |
| `models/` | Локальная модель эмбеддингов и кэш загрузок. |
| `glossary.db` | Локальная сборка SQLite и FTS5. Сервис пересоздаёт её из канонических записей и реестра обложек. |

SQLite, модель, рабочие кадры и кэши перевода и эмбеддингов хранятся локально. Для добавления выпуска сверяйте `pdf_path`, `original_path`, `ru_path` и хэши в записи. Новые исходные изображения добавляйте в Git по этим путям через `git add -f`. Команды импорта и пересборки описаны в [README проекта](../README.md#данные-и-индекс).
