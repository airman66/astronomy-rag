# Поиск по цитатам OAE на индексе v3

Набор содержит 48 вопросов RU/EN по 24 статьям, затронутым переразбиением.
Совпадение засчитывается, когда в контекст попала заданная цитата из нужного
раздела. Корпус содержит 4 964 чанка. Хэш чанков начинается на `2744727e`.
Поиск Qwen3 использовал локальный llama.cpp, сборка 10080 (`fd41bf65a`).

| Проверка | Qwen3-Embedding-8B-Q4_K_M | multilingual-e5-small |
| --- | ---: | ---: |
| Цитата в первых 6 векторных результатах | 35/48 | 35/48 |
| Цитата в первых 40 векторных результатах | 46/48 | 46/48 |
| Цитата в собранном гибридном контексте | 34/48 | 34/48 |
| Прежний набор retrieval | 34/34 | 34/34 |

E5 использовал ONNX-модель ревизии `614241f622f53c4eeff9890bdc4f31cfecc418b3`,
384 измерения, среднее по незамаскированным токенам и L2-нормализацию.
Все чанки переэмбеддированы с префиксом `passage:`, запросы с `query:`.
Для сравнения использованы тот же FTS и тот же код объединения результатов и
сборки контекста. В гибридном прогоне каждая модель нашла четыре цитаты,
которые пропустила другая. Замена модели в сервисе потребует калибровки порога сходства.

На этой машине p95 для тёплых запросов был около 364 мс через HTTP к Qwen3 и
4 мс для E5 внутри процесса на CPU. Эти числа характеризуют конкретные пути
вызова. Задержку HTTP для E5 и задержку полного ответа LLM этот замер не оценивает.

В 36 случаях точная цитата присутствовала уже в объединённой выдаче Qwen3 до
сборки контекста. Дополнительное взвешивание ранга по пересечению стемов
запроса и текста кандидата подняло OAE до 36/48 и снизило прежний набор до
33/34. Повторное использование векторного текста при поиске внутри выбранной
статьи дало 33/48 и 34/34 соответственно. Оба варианта остались экспериментами.

RunPod отклонил ключ API, DeepSeek сообщил об исчерпанном балансе. Полная оценка
ответов LLM остановилась на вызове провайдера. Результат о качестве ответов
с новой моделью эмбеддингов пока отсутствует.
