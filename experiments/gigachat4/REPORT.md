**Поиск.** Гибридный поиск отработал на 97 запросах, ещё 3 явно запросили `general`. Все фрагменты из рубрики найдены для 68 из 79 запросов с обязательными источниками. Для сопоставлений показатель 9/14. В q048 до обеих моделей не дошёл нужный абзац удалённых наблюдений. В q057 обоим хватило материала для правильного физического объяснения, но в пакет не попал нужный раздел второй статьи. Строгий балл также учитывает промахи по ожидаемому режиму. Например, в q083 обе модели правильно рассчитали ухудшение разрешения интерферометра и выбрали `explain` при эталоне `general`.

**Различия.** GigaChat точнее маршрутизировал ответы. Например, в q044 он выбрал `article` для вопроса по названной статье, тогда как DeepSeek вернул корректное объяснение в `explain`. DeepSeek чаще проходил строгую оценку общих вопросов. В q091 GigaChat правильно разделил компоненты скорости, но ошибся в том, что коррекция движения Солнца якобы не нужна для лучевой скорости. В q010 обе модели выбрали правильную карточку CME и получили из неё одну и ту же научную неточность про спектр солнечной вспышки. [NASA о спектре вспышек](https://science.nasa.gov/sun/solar-storms-and-flares/)

**Протокол.** Один проход на модель с одним боевым системным промптом и байт-в-байт одинаковым содержимым сообщений в каждой паре, лимит 8192 токена и по два параллельных запроса у каждого провайдера. Рубрика и контрольные цитаты оставались в оценщике. Codex сверил 193 ответа без меток провайдера после генерации. DeepSeek вернул три обрыва по лимиту и два ответа вне схемы. У GigaChat один HTTP 500 и один ответ вне схемы. Стартовый пробный прогон GigaChat с параметрами по умолчанию исключён после проверки режимов на отдельных арифметических задачах. Он не использовался для выбора вопросов, рубрики или промпта.

Cloud.ru подтвердил ID `GigaChat-4-708B-A41B:4.0.17.11`. При `reasoning_effort=high` шлюз вернул рассуждение, а `max` и `xhigh` отклонил. Точный внутренний бюджет GigaChat неизвестен. Результат относится к этим API-настройкам и одному прогону. [Архитектура, обучение и настройки GigaChat](README.md)
