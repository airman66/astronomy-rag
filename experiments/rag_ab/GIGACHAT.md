## Методика

50 контрольных вопросов, по 25 на русском и английском. Для каждого вопроса обе модели получают одинаковые фрагменты из одного снимка гибридного поиска, один системный промпт и лимит 768 выходных токенов. Поиск использует Qwen3-Embedding-8B и FAISS. Промпт A получает до 6 фрагментов, промпт B — до 8. Бюджет контекста в обоих случаях составляет 8 500 символов.

Сбер описывает выпуск как GigaChat 3 версии 3.5. Идентификатор для запросов через API — `GigaChat-3-Ultra`. Для структурированного ответа GigaChat используется `json_schema` на основе `ModelReply`, для DeepSeek — `json_object`. Оба ответа валидируются одной схемой и проходят через `render` сервиса. [История выпусков](https://developers.sber.ru/docs/ru/gigachat/models/updates) · [Структурированный вывод](https://developers.sber.ru/docs/ru/gigachat/guides/structured-output)

Тест засчитывается при совпадении ожидаемых режима и полноты, корректных ссылках и прохождении проверок фактов по текстовым шаблонам. Один прогон на вопрос. Для задержек генерации берётся время вызова модели после прогрева OAuth, без поиска.

Для A использовали промпт `2026-11-18.2`. Гибридный поиск выполнили для 42 вопросов. Восемь запросов в явном режиме `general` получают пустой контекст. Отдельный набор из 48 вопросов на точное цитирование OAE в сравнение моделей не входит.

## Повторить

Нужны `DEEPSEEK_API_KEY` и авторизационный ключ `GIGACHAT_API_KEY` в локальном `.env` или окружении. Запустить локальный сервер эмбеддингов по инструкции в README репозитория.

Таблицы для A и B (`2026-11-25.1`) относятся к коммиту `d2909a8`. В текущем коде `--variant B` запускает рабочую версию промпта из `SPEC.md`.

```sh
export RAG_AB_OUTPUT_DIR="$(mktemp -d)"
mkdir -p "$RAG_AB_OUTPUT_DIR"
curl -fsSL https://gu-st.ru/content/lending/russian_trusted_root_ca_pem.crt \
  -o "$RAG_AB_OUTPUT_DIR/root-ca.crt"
export GIGACHAT_CA_FILE="$RAG_AB_OUTPUT_DIR/root-ca.crt"
export EMBEDDING_URL=http://127.0.0.1:8082/v1/embeddings
export ASSISTANT_PROVIDER=deepseek DEEPSEEK_MODEL=deepseek-flash ASSISTANT_MAX_OUTPUT_TOKENS=768

.venv/bin/python -m experiments.rag_ab.retrieval --legacy
.venv/bin/python -m experiments.rag_ab.providers --variant B
```

Снимок поиска, ответы, конфигурация и оценки сохраняются в `RAG_AB_OUTPUT_DIR`. Для возобновления прерванного прогона повторите команду сравнения с тем же вариантом и снимком. Для другого варианта или новой версии упаковки возьмите отдельный каталог и пересоберите снимок. Исторические результаты воспроизводятся на коммите, указанном выше.
