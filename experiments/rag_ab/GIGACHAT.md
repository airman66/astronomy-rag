DeepSeek одновременно назвал базис в 1 а.е. и наблюдения с интервалом в полгода. Текстовая проверка факта пропустила это противоречие.

- По детектированию экзопланет обе модели процитировали нужные разделы статьи и прошли проверку двух фактов. Роутинг выбрал `explain`, тогда как набор ожидал `article`. Всего обе модели прошли 2 из 6 тестов на режим статьи.

## Методика

50 контрольных вопросов, по 25 на русском и английском. Для каждого вопроса обе модели получают одинаковые фрагменты из одного снимка гибридного поиска, один системный промпт и лимит 768 выходных токенов. Поиск использует Qwen3-Embedding-8B и FAISS. Упаковка передаёт до 6 фрагментов, до 8 500 символов.

Сбер описывает выпуск как GigaChat 3 версии 3.5. Идентификатор для запросов через API — `GigaChat-3-Ultra`. Для структурированного ответа GigaChat используется `json_schema` на основе `ModelReply`, для DeepSeek — `json_object`. Оба ответа валидируются одной схемой и проходят через `render` сервиса. [История выпусков](https://developers.sber.ru/docs/ru/gigachat/models/updates) · [Структурированный вывод](https://developers.sber.ru/docs/ru/gigachat/guides/structured-output)

Тест засчитывается при совпадении ожидаемых режима и полноты, корректных ссылках и прохождении проверок фактов по текстовым шаблонам. Один прогон на вопрос. Для задержек генерации берётся время вызова модели после прогрева OAuth, без поиска.

API фактически вернули `GigaChat-3-Ultra:32.9.16.9` и `deepseek-flash`. Промпт `2026-11-18.2`. Снимок гибридного поиска покрывает 42 вопроса, ещё 8 с явным режимом `general` получают пустой контекст. Набор из 48 вопросов на точное цитирование OAE в этом прогоне не участвовал.

## Повторить

Нужны `DEEPSEEK_API_KEY` и авторизационный ключ `GIGACHAT_API_KEY` в локальном `.env` или окружении. Запустить локальный сервер эмбеддингов по инструкции в README репозитория.

```sh
export RAG_AB_OUTPUT_DIR=.git/gigachat-experiment
mkdir -p "$RAG_AB_OUTPUT_DIR"
curl -fsSL https://gu-st.ru/content/lending/russian_trusted_root_ca_pem.crt \
  -o "$RAG_AB_OUTPUT_DIR/root-ca.crt"
export GIGACHAT_CA_FILE="$RAG_AB_OUTPUT_DIR/root-ca.crt"
export EMBEDDING_URL=http://127.0.0.1:8082/v1/embeddings
export ASSISTANT_PROVIDER=deepseek DEEPSEEK_MODEL=deepseek-flash ASSISTANT_MAX_OUTPUT_TOKENS=768

.venv/bin/python -m experiments.rag_ab.retrieval --legacy
.venv/bin/python -m experiments.rag_ab.providers
```

Снимок поиска, ответы, конфигурация и оценки сохраняются в `RAG_AB_OUTPUT_DIR`. Для возобновления прерванного прогона повторно запустить только `experiments.rag_ab.providers` с тем же снимком. Для независимого прогона выбрать новый каталог.
